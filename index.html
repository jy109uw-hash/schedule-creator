Appointment windows

6 · Task mix

How the rest of your flexible time is split. Block = preferred chunk size. Anything left over becomes flex / catch-up time.

How it works
  • Flexible time = paid working time minus fixed commitments and breaks. Appointment percentages are shares of this. Each task type can instead use % of FTE (your paid hours, e.g. 25% of 35 h = 8.75 h) or a fixed number of hours per week.
  • Order of placement: fixed commitments → meals → breaks → time set aside for tasks → appointments (spread evenly across days) → rest of the task mix → flex.
  • Maximize patient time books every appointment that fits inside your windows, with no daily cap. Task-mix percentages then apply to whatever time is left.
  • Appointments get a notes buffer straight after, counted as client time.
  • Settings save automatically in this browser only — nothing is sent anywhere. Use Export to back them up or move them to another computer.
  • Please don't enter client names or health information; slots are generic.
